Your data stays on your machine

There is no server. There is nothing to breach.

Everything runs locally on your PC. If you link Google, the tool asks for the two narrowest scopes that do the job: calendar.events.readonly, and gmail.metadata — message headers only. It cannot read the body of an email or open an attachment, and it cannot send, delete or change anything. Your token is stored on your own disk and revoked with a single command.

Worth knowing: mail that appears on your wallpaper is readable by anyone who sees your screen, including in a screen share. That is the point of the feature — just choose it deliberately.

Questions

Does it need an API key or a subscription?
No. No keys, no accounts, no AI billing. It reads public RSS feeds and the public GitHub search API.
Does it use AI to write the wallpaper?
No. It is deterministic code — feed parsing, filtering and a layout engine. Nothing is generated by a model.
Why is the download around 88 MB?
The Node runtime is bundled in, so there is nothing else to install. It is one file with no dependencies.
Windows says it protected my PC.
The binary is not yet code-signed, so SmartScreen warns on first run. Click More info, then Run anyway.
How do I stop it?
ai-news-wallpaper stop removes the scheduled task. Your current wallpaper stays as it is.
Does it run while my PC is asleep?
No — it refreshes while you are logged in, and catches up with one run when you come back.
